Acesso ao GitHub

As correções são gravadas no arquivo correcoes.json do repositório. Para isso, cada pessoa da equipe usa uma chave de acesso do GitHub, guardada só neste navegador.

  1. Entre no GitHub com uma conta que tenha acesso ao repositório e abra github.com/settings/personal-access-tokens/new.
  2. Dê um nome (por exemplo, "revisão exterminadores") e escolha a validade.
  3. Em Repository access, marque Only select repositories e escolha jamesgorgen/exterminadores-do-futuro.
  4. Em Permissions, procure Contents e escolha Read and write.
  5. Clique em Generate token, copie a chave e cole abaixo.
