Emendas Dossiês

Dados oficiais da API de Dados Abertos da Câmara dos Deputados e da API de Dados Abertos Legislativos do Senado Federal, coletados todos os dias. A classificação das pautas é feita por inteligência artificial a partir das ementas e serve como triagem. Confira o texto integral antes de divulgar.

Os dados completos, em formato aberto, estão na pasta de dados do projeto no GitHub.
