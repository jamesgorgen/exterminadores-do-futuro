do futuro

O que a direita faz no Congresso, todos os dias.

Um observatório dos movimentos da direita e da extrema-direita na Câmara e no Senado. Cada projeto apresentado e cada voto, com os dados oficiais das duas Casas, atualizados diariamente.

Fazemos a checagem dos projetos e das votações dos parlamentares conservadores e reacionários que ameaçam nossos direitos e o Brasil.

Emendas

Dados oficiais da API de Dados Abertos da Câmara dos Deputados e da API de Dados Abertos Legislativos do Senado Federal, coletados todos os dias. A classificação das pautas é feita por inteligência artificial a partir das ementas e serve como triagem. Confira o texto integral antes de divulgar.

Os dados completos, em formato aberto, estão na pasta de dados do projeto no GitHub.
